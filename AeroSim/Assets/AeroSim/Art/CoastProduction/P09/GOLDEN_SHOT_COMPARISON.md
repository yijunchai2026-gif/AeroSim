# P09 黄金镜头对比说明

## 比较纪律

1. Reference 只使用 `source/coast-lookdev-reference.png` 的构图、明度层级、材质分色和大气纵深；不能把它当运行时背景、HDRI 或物理标定值。
2. Candidate 必须固定同一 build、High、2560×1440 原生 PNG、Pacific Coast、seed `41001`、同 Camera pose/FOV、同内部分辨率与 UI scale。自动曝光、动态 FOV、DOF、强色差和颗粒关闭。
3. 每次只改变 manifest 指定的天气或评审变量；记录 resolved parameters。比较图禁止后期二次调色、缩放或裁剪。
4. 参考图没有对应运行天气/镜头时，只评估共同视觉原则，不做像素差或“匹配通过”。静态包不产生 PASS。

## 参考图读取

- **明度**：云层高光有纹理；左前景岩壁和树丛保留暗部细节；海面/浪花亮于岩石但不与天空粘连。
- **色彩**：整体蓝灰、低到中饱和；岩石近中性冷灰；植被深橄榄/针叶绿；设施混凝土与镀锌钢低饱和，安全黄仅作小面积识别。
- **层次**：前景黑位最深且细节最密，中景设施可读，远岬与山体由雾抬升；云影是大尺度低频变化，不是脏贴花。
- **水岸**：远海与潮池色域不同；湿岩更暗、更平滑但不整体蓝染；白沫只占破浪与岸缘。

## 建议对比版式

- 左：Reference 全图或明确标注的等比区域；中：Candidate；右：Difference/false-color 仅作诊断，不作审美分数。
- 下方 metadata 条必须显示 profileId、天气、时间、seed、Camera pose、v/hFOV、分辨率、build/source、pipeline、quality。
- 每镜头补充波形/直方图只用于发现剪切和漂移；不得用统计图替代人工美术评审。
